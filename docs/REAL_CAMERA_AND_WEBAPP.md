# ต่อกล้อง Basler จริง และรัน Web app บน localhost

คู่มือนี้รวมขั้นตอนและปัญหาที่เจอจริงระหว่างเตรียมอบรม กับกล้อง **Basler acA2440-20gc (GigE, 5 MP)** บน Mac และ Windows

---

## ส่วนที่ 1: ต่อกล้องจริง

### อุปกรณ์ที่ต้องมี
| อุปกรณ์ | หมายเหตุ |
|---|---|
| กล้อง GigE + เลนส์ C-mount | ถอดฝาเลนส์ก่อนใช้ |
| PoE switch หรือ PoE injector | จ่ายไฟให้กล้องผ่านสาย LAN  **ต้องเป็น Gigabit (1000 Mbps)** |
| สาย LAN Cat5e ขึ้นไป | สายเก่าหรือเสียบหลวม จะลดความเร็วเหลือ 100 Mbps |
| ช่อง LAN ที่คอมพิวเตอร์ | โน้ตบุ๊กไม่มีช่อง LAN ใช้อะแดปเตอร์ USB-C เป็น LAN **รุ่น Gigabit** |
| ไฟส่องชิ้นงาน | ไฟวงแหวน ไฟ LED หรือไฟฉายมือถือ (ช่วงทดลอง) |

### ขั้นตอน
1. **ต่อสาย:** กล้อง → PoE → คอมพิวเตอร์  รอไฟที่ตัวกล้องติด 10–20 วินาที
2. **ตั้งการ์ดแลน** เป็น Auto IP / DHCP  กล้องและคอมพิวเตอร์จะได้ IP แบบ 169.254.x.x เอง
3. **เปิด pylon Viewer** ดับเบิลคลิกชื่อกล้อง กด Continuous Shot (ภาพสด) แล้วตั้งภาพให้ดี
   - **หมุนแหวนรูรับแสง (Iris)** ไปที่ตัวเลขน้อย เช่น 1.4–4  (ถ้าอยู่ที่ C = ปิดสนิท ภาพจะมืดเกือบดำ)
   - **หมุนแหวนโฟกัส** จนภาพคม
   - ตั้ง **Exposure** ให้ภาพสว่างพอดี  ปรับ **White Balance** (Balance White Auto = Once) ถ้าภาพติดโทนเขียว
4. **ปิด pylon Viewer** ทุกครั้งก่อนใช้โปรแกรมอื่น  กล้องเปิดได้ทีละโปรแกรม
5. **ใน notebook:** ตั้ง `SOURCE = 'basler'` หรือเรียก `grab_one('basler', exposure_us=20000)`
   (ไม่ต้อง Restart Kernel เมื่อสลับกับกล้องจำลองแล้ว โปรแกรมเลือกกล้องให้เอง)

### ตรวจว่าสายเป็น Gigabit จริงไหม
```python
from pypylon import pylon
cam = pylon.InstantCamera(pylon.TlFactory.GetInstance().CreateFirstDevice())
cam.Open()
print('ความเร็วสาย (Mbps):', cam.GevLinkSpeed.Value)
print('ภาพต่อวินาทีสูงสุด:', round(cam.ResultingFrameRateAbs.Value, 1))
cam.Close()
```
ต้องได้ **1000 Mbps** และราว 20 ภาพต่อวินาที  ถ้าได้ 100 Mbps จะเหลือราว 2 ภาพต่อวินาที

### ปัญหาที่เจอจริง และวิธีแก้
| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `ไม่พบกล้อง` | สายหลุด ไฟ PoE ดับ การ์ดแลนไม่ใช่ Auto IP หรือมีโปรแกรมอื่นเปิดกล้องอยู่ | เช็กไฟที่กล้อง ปิด pylon Viewer / notebook อื่น ตั้ง Auto IP |
| ภาพดำ หรือมืดมากแม้เพิ่ม Exposure | แหวนรูรับแสงอยู่ที่ C ฝาเลนส์ปิด หรือไม่มีแสง | หมุนรูรับแสงไป 1.4–4 ถอดฝา เปิดไฟ |
| ภาพมาไม่ครบ (`incompletely grabbed`) แล้วเกิด error ตอนแปลงสี | อะแดปเตอร์ LAN รับแพ็กเก็ตไม่ทัน ภาพ 5 MP ส่งมาไม่ครบ | `vision_camera.py` ตั้ง `GevSCPD` และรอแพ็กเก็ตนานขึ้นให้แล้ว ถ้ายังเกิด ใช้ AOI ลดขนาดภาพ |
| ถ่ายได้แค่ ~2 ภาพต่อวินาที | สายหรืออะแดปเตอร์เชื่อมต่อที่ 100 Mbps | เปลี่ยนเป็นอุปกรณ์ Gigabit ทั้งเส้น |
| ภาพติดโทนเขียว | ยังไม่ได้ตั้ง White Balance | Balance White Auto = Once ใน pylon Viewer หรือปุ่มในแอป |
| ปรับ Gain แล้วแทบไม่เปลี่ยน | กล้องรุ่นนี้ใช้ GainRaw (หน่วยของกล้อง ไม่ใช่ dB) | ใช้ Exposure และแสงเป็นหลัก |
| ครั้งแรกที่ถ่ายช้า ~5 วินาที | การเปิดกล้อง GigE ใช้เวลา | เปิดกล้องค้างไว้แล้วถ่ายซ้ำ (web app ทำให้แล้ว ครั้งต่อไป ~0.5 วินาที) |

### ข้อจำกัดที่ควรรู้
- **notebook ไม่เหมาะกับภาพสดความเร็วสูง** `grab_one()` เปิดและปิดกล้องทุกครั้งเพื่อไม่ให้กล้องค้าง จึงช้า เหมาะกับถ่ายทีละภาพ
- **กล้องจำลองไม่เปลี่ยนภาพตาม Exposure / Gain** ต้องใช้กล้องจริงจึงเห็นผล (notebook 02b จำลองผลให้ด้วยโค้ด)
- **ค่าที่จูนกับภาพตัวอย่าง ใช้กับกล้องจริงไม่ได้ทันที** แสง สี และขนาดภาพต่างกัน ต้องจูน HSV, พื้นที่ขั้นต่ำ และ Exposure ใหม่ (ภาพจริงใหญ่กว่าภาพตัวอย่างราว 16 เท่า พื้นที่ขั้นต่ำจึงต้องเพิ่มตาม)
- **ไลน์ผลิตจริงใช้ Hardware Trigger** (เซนเซอร์ต่อสายเข้ากล้อง) และโปรแกรมติดตั้งบนเครื่อง ชุดนี้ใช้ Software Trigger สำหรับการเรียน

## ส่วนที่ 2: รัน Web app (สถานีตรวจชิ้นงาน) บน localhost

### ติดตั้ง (ครั้งเดียว)
```
python -m pip install -r requirements.txt
```
(มี streamlit และ pandas อยู่ในรายการแล้ว  Mac ใช้ `python3`)

### เปิดแอป
เปิด Terminal ที่โฟลเดอร์ชุด Workshop แล้วพิมพ์
```
python -m streamlit run app/inspection_app.py
```
เบราว์เซอร์จะเปิด **http://localhost:8501** ให้เอง  ถ้าไม่เปิด ให้พิมพ์ที่อยู่นี้เอง
**ปิดแอป:** กลับไปที่ Terminal กด `Ctrl + C`

### ใช้งาน
1. **แถบซ้าย ข้อ 1** เลือกแหล่งภาพ: ภาพตัวอย่าง / อัปโหลดภาพ / กล้องจำลอง / กล้อง Basler จริง / Webcam
2. **ข้อ 2 กล้อง** สำหรับกล้องจริง เปิด **ใช้ค่ากล้องที่ตั้งไว้ใน pylon Viewer** (แนะนำ) แอปจะไม่แก้ค่าที่ตั้งไว้
3. **ข้อ 3 เงื่อนไขตรวจ** ช่วงสี H, ความสด S, ความสว่าง V, พื้นที่ขั้นต่ำ, จำนวนที่ต้องมี
4. กด **Trigger** = ถ่าย 1 ภาพ ตรวจ บันทึกผล  หรือเปิด **ภาพสด (Live)** ตรวจต่อเนื่อง
5. ด้านล่างมีตารางบันทึกผล สถิติ OK/NG และปุ่ม **ดาวน์โหลด CSV**
6. กด **ปิดกล้อง** ในแถบซ้ายก่อนกลับไปใช้ pylon Viewer หรือ notebook

### ให้คนอื่นในวง LAN เดียวกันเปิดดู
```
python -m streamlit run app/inspection_app.py --server.address 0.0.0.0
```
คนอื่นเปิด `http://<IP ของเครื่องนี้>:8501`  (กล้องยังต่ออยู่กับเครื่องที่รันแอป)  ใช้ในวงที่ไว้ใจได้เท่านั้น แอปไม่มีระบบล็อกอิน

### ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| `streamlit` ไม่รู้จักคำสั่ง | ใช้ `python -m streamlit ...` หรือติดตั้งใหม่ |
| `Port 8501 is already in use` | มีแอปเปิดค้างอยู่ ปิด Terminal เดิม หรือเพิ่ม `--server.port 8502` |
| กดกล้องจริงแล้วขึ้น ไม่พบกล้อง | ปิด pylon Viewer และ notebook ที่ใช้กล้องอยู่ |
| Webcam ได้ภาพดำบน Mac | อนุญาตให้ Terminal ใช้กล้อง: System Settings → Privacy & Security → Camera |
| ภาพสดกระตุก | ปกติของ web app (กล้อง GigE ที่ 100 Mbps อัปเดตราว 1 ภาพต่อวินาที) |

### ข้อจำกัดของ Web app
- เหมาะกับ **การเรียน ทดลอง ทำต้นแบบ และหน้าจอสรุปผล**  ไม่ใช่สถานีตรวจในไลน์ที่ต้องตอบสนองในระดับมิลลิวินาทีและต่อ PLC
- ภาพสดส่งผ่านเบราว์เซอร์ทีละภาพ ลื่นสู้ pylon Viewer ไม่ได้  ใช้ pylon Viewer สำหรับดูภาพสดและตั้งกล้อง
- เปิดหลายแท็บพร้อมกันได้ แต่ใช้กล้องตัวเดียวกัน แอปจะสลับให้อ่านทีละคำสั่ง
- บันทึกผลอยู่ในหน่วยความจำ ปิดแอปแล้วหาย  กดดาวน์โหลด CSV ก่อนปิด
