# คำย่อและคำศัพท์ที่ควรรู้

ใช้เปิดดูระหว่างทำ Workshop และทบทวนก่อนทำแบบทดสอบ  คำที่มี ★ คือแนวคิดที่อยู่ในแบบทดสอบ

## 1. คำย่อ

### กล้องและฮาร์ดแวร์
| คำย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| MV ★ | Machine Vision | ระบบกล้อง + แสง + โปรแกรม ที่ตรวจชิ้นงานอัตโนมัติในโรงงาน |
| CV | Computer Vision | ศาสตร์ที่ทำให้คอมพิวเตอร์เข้าใจภาพ |
| FOV ★ | Field of View | ขนาดพื้นที่ที่กล้องมองเห็นในภาพเดียว |
| DOF | Depth of Field | ช่วงระยะใกล้–ไกลที่ภาพยังคมชัด |
| AOI | Area of Interest | ตัดภาพตั้งแต่ในตัวกล้อง ภาพเล็กลง ถ่ายได้เร็วขึ้น |
| ROI | Region of Interest | กรอบบริเวณที่สนใจในภาพ ใช้ตรวจเฉพาะส่วน (ROI map) |
| MP ★ | Megapixel | ล้านพิกเซล  เช่น 1920 × 1080 = 2.1 MP |
| fps | frames per second | จำนวนภาพต่อวินาที |
| GigE | Gigabit Ethernet | ต่อกล้องผ่านสาย LAN ความเร็ว 1 Gbps |
| PoE | Power over Ethernet | ส่งไฟเลี้ยงกล้องไปพร้อมสาย LAN |
| USB3 | USB 3.0 Vision | ต่อกล้องผ่าน USB 3 สายสั้น ความเร็วสูง |
| SDK | Software Development Kit | ชุดเครื่องมือเขียนโปรแกรมควบคุมกล้อง เช่น pylon |
| PLC | Programmable Logic Controller | ตัวควบคุมเครื่องจักรในไลน์ผลิต รับผล OK/NG จากระบบ Vision |
| I/O | Input / Output | สายสัญญาณเข้าออก เช่น สั่ง Trigger กล้อง ส่งผลไปเครื่องคัดแยก |

### ภาพและสี
| คำย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| px | pixel | จุดเล็กที่สุดของภาพ |
| RGB ★ / BGR | Red Green Blue | ระบบสีแบบผสมแสง ใช้กับจอและกล้อง  OpenCV เรียงเป็น B, G, R |
| HSV ★ | Hue Saturation Value | บอกสีด้วย 3 คำถาม: สีอะไร / สดแค่ไหน / สว่างแค่ไหน |
| px/mm | pixel per millimeter | กี่พิกเซลต่อ 1 มม. ใช้แปลงพิกเซลเป็นขนาดจริง |
| OCR | Optical Character Recognition | อ่านตัวอักษรจากภาพ |

### การตรวจและการผลิต
| คำย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| OK / NG | OK / No Good | ผ่าน / ไม่ผ่าน |
| QC | Quality Control | การควบคุมคุณภาพ หรือฝ่าย QC |
| LOT | Lot number | เลขล็อตการผลิต ใช้ตามย้อนกลับเมื่อมีปัญหา |
| MFG / EXP | Manufacturing / Expiry date | วันผลิต / วันหมดอายุ |
| CSV | Comma-Separated Values | ไฟล์ตารางข้อความ เปิดด้วย Excel ได้ |

### อัลกอริทึมและ AI
| คำย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| AI | Artificial Intelligence | ปัญญาประดิษฐ์ |
| ML | Machine Learning | ให้คอมพิวเตอร์เรียนรู้กฎเองจากตัวอย่างที่มีเฉลย |
| DL | Deep Learning | ML แบบโครงข่ายประสาทหลายชั้น เรียน Features เองจากภาพ |
| HOG | Histogram of Oriented Gradients | สรุปทิศทางของขอบในภาพ ใช้เป็น Features |
| SVM | Support Vector Machine | ตัวจำแนกแบบคลาสสิก สอนเร็ว (notebook 07) |
| ECC | Enhanced Correlation Coefficient | วิธีจัดตำแหน่งภาพให้ทับกับภาพอ้างอิง (notebook 10) |
| YOLO | You Only Look Once | AI หาวัตถุและตีกรอบ ใช้งานจริงแพร่หลาย |
| SAM | Segment Anything Model | AI แบ่งขอบเขตวัตถุในภาพโดยไม่ต้องสอนใหม่ |
| GPU | Graphics Processing Unit | การ์ดจอ ช่วยให้สอน AI เร็วขึ้นมาก |

## 2. คำศัพท์สำคัญ

### ระบบ กล้อง เลนส์ และแสง
| คำศัพท์ | ความหมาย |
|---|---|
| Machine Vision ★ | ใช้กล้องและคอมพิวเตอร์ตรวจ วัด อ่าน หรือนำทางชิ้นงานแทนตาคน ในงานอุตสาหกรรม |
| ลำดับการทำงานของระบบ ★ | แสงส่องชิ้นงาน → แสงสะท้อนผ่าน**เลนส์** → ตกบน**เซนเซอร์**กล้อง → ส่งภาพเข้าคอมพิวเตอร์ → ประมวลผล → ตัดสิน |
| Area Scan Camera | กล้องถ่ายภาพเป็นพื้นที่สี่เหลี่ยมทีละภาพ (กล้องในห้องเป็นแบบนี้) |
| Line Scan Camera | กล้องถ่ายทีละเส้น ต่อกันเป็นภาพ ใช้กับชิ้นงานยาวต่อเนื่อง เช่น ม้วนผ้า แผ่นเหล็ก |
| 3D Camera / Point Cloud ★ | กล้อง 3 มิติ ให้ข้อมูลเป็น**กลุ่มจุดที่มีพิกัด X Y Z** เรียกว่า Point Cloud ใช้วัดความสูง ปริมาตร |
| Resolution ★ | จำนวนพิกเซลของกล้อง  ถ้า Resolution เท่าเดิมแต่ FOV กว้างขึ้น รายละเอียดต่อพื้นที่จะ**ลดลง** |
| Exposure | เวลาที่เซนเซอร์เปิดรับแสง  นานขึ้น = สว่างขึ้น แต่ชิ้นงานที่เคลื่อนที่จะเบลอ |
| Gain | การขยายสัญญาณภาพ  สูงขึ้น = สว่างขึ้น แต่จุดรบกวน (Noise) มากขึ้น |
| Pixel Format | รูปแบบข้อมูลภาพที่กล้องส่ง เช่น Mono8 (ขาวดำ), BayerRG8 (ข้อมูลดิบกล้องสี), BGR8 (สี) |
| Trigger | สัญญาณสั่งให้กล้องถ่าย 1 ภาพ เมื่อชิ้นงานมาถึง (จากเซนเซอร์หรือซอฟต์แวร์) |
| Emulated Camera | กล้องจำลองของ Basler ใช้ทดลองโปรแกรมโดยไม่ต้องมีกล้องจริง |
| Focal Length | ทางยาวโฟกัสของเลนส์  มาก = มุมแคบ ซูมใกล้  น้อย = มุมกว้าง |
| Aperture / F-number | รูรับแสงของเลนส์  ตัวเลขน้อย (เช่น 1.4) = เปิดกว้าง สว่าง แต่ DOF แคบ |
| Telecentric Lens | เลนส์ที่ขนาดวัตถุในภาพไม่เปลี่ยนตามระยะ ใช้กับงานวัดขนาดแม่นยำ |
| Backlight | ไฟส่องจากด้านหลังชิ้นงาน ได้เงาดำคมชัด เหมาะกับวัดขนาดและหาขอบ |
| Ring Light | ไฟวงแหวนรอบเลนส์ ใช้ทั่วไป |
| Dome Light | ไฟโดมกระจายแสงรอบด้าน ลดแสงสะท้อนบนผิวมันวาว |
| Coaxial Light | ไฟส่องตามแนวแกนเลนส์ เหมาะกับผิวเรียบสะท้อนแสง |
| Low Angle / Dark Field | ไฟส่องเฉียงต่ำ ทำให้รอยขีด ตัวนูน เห็นเด่น |
| Jig / Fixture | อุปกรณ์จับยึดชิ้นงานให้อยู่ตำแหน่งเดิมทุกครั้ง ทำให้การตรวจแม่นและง่ายขึ้นมาก |
| Enclosure | กล่องครอบสถานีตรวจ กันแสงภายนอก ให้แสงคงที่ |

### ภาพดิจิทัล
| คำศัพท์ | ความหมาย |
|---|---|
| Pixel ★ | **หน่วยที่เล็กที่สุดของภาพดิจิทัล** แต่ละพิกเซลเก็บค่าตัวเลข |
| Grayscale | ภาพเทา 1 ตัวเลขต่อพิกเซล (0 ดำ ถึง 255 ขาว) |
| Binary Image ★ | ภาพที่มีแค่ 2 ค่า คือ ขาวกับดำ  ได้จากการทำ **Threshold** |
| Channel | ชั้นสีของภาพ  ภาพสีมี 3 ชั้น (B, G, R) |
| Array | ตารางตัวเลข  ภาพสีคือ Array 3 มิติ (สูง × กว้าง × ชั้นสี) |
| RGB ★ | ระบบสีที่ใช้**แสดงผลบนจอ**และกล้อง ผสมแสงแดง เขียว น้ำเงิน |
| HSV ★ | **Hue** (เฉดสี) **Saturation** (ความสด) **Value** (ความสว่าง)  แยกวัตถุตามสีได้ดีกว่า RGB เมื่อแสงเปลี่ยน |
| Histogram | กราฟนับจำนวนพิกเซลแต่ละระดับความสว่างหรือสี |
| Noise | จุดรบกวนในภาพ เพิ่มเมื่อ Gain สูงหรือแสงน้อย |

### การประมวลผลภาพ
| คำศัพท์ | ความหมาย |
|---|---|
| OpenCV ★ | **ไลบรารีโอเพนซอร์ส**สำหรับ Computer Vision ใช้ฟรีแม้ในเชิงพาณิชย์ |
| Threshold ★ | กำหนดค่าตัดแบ่ง พิกเซลที่เกินค่าเป็นขาว ไม่เกินเป็นดำ  ถ้าตั้ง**สูงเกินไป วัตถุบางส่วนจะหายไป** |
| Otsu | วิธีให้คอมพิวเตอร์เลือกค่า Threshold ที่เหมาะสมเอง (ชื่อนักวิจัย) |
| Canny ★ | วิธี**หาขอบวัตถุ**ในภาพ (ชื่อผู้คิดค้น) |
| Mask | ภาพขาวดำที่บอกว่าพิกเซลไหนอยู่ในเงื่อนไข เช่น เป็นสีแดง |
| Contour | เส้นรอบวัตถุที่หาได้จาก Mask ใช้นับ วัดพื้นที่ ตีกรอบ |
| Bounding Box | กรอบสี่เหลี่ยมที่ล้อมวัตถุพอดี |
| Area | พื้นที่ของวัตถุเป็นจำนวนพิกเซล ใช้กรองชิ้นเล็กชิ้นใหญ่ |
| Circularity ★ | ความกลม = 4π × พื้นที่ ÷ เส้นรอบรูป²  **วงกลมสมบูรณ์ = 1.0** |
| Morphology | การปรับรูปร่างใน Mask: Erode (หด), Dilate (ขยาย), Open (ลบจุดเล็ก), Close (อุดรู) |
| Template Matching | หาตำแหน่งของภาพแม่แบบในภาพใหญ่ เช่น หาฉลาก |
| Golden Sample / Reference | ภาพชิ้นงานที่ถูกต้อง ใช้เทียบหาความต่าง |
| Watershed | วิธีแยกวัตถุที่วางติดกัน (เปรียบภาพเป็นภูเขาแล้วแบ่งเขตน้ำ) |
| Calibration | การสอบเทียบ แปลงพิกเซลเป็นหน่วยจริง ด้วยวัตถุที่รู้ขนาด |
| Deskew | หมุนภาพที่เอียงให้ตรงก่อนประมวลผล เช่น ก่อน OCR |
| Alignment | จัดตำแหน่งภาพให้ทับกับภาพอ้างอิง |

### การตรวจในโรงงาน
| คำศัพท์ | ความหมาย |
|---|---|
| False Reject | ของดีแต่ระบบบอก NG  เสียของดีทิ้ง |
| Escape | ของเสียแต่ระบบบอก OK  หลุดถึงลูกค้า **ร้ายแรงที่สุด** |
| Yield | % ของชิ้นงานที่ผ่าน |
| Cycle Time / Takt Time | เวลาต่อชิ้นงาน 1 ชิ้นในไลน์ ระบบตรวจต้องเร็วกว่านี้ |
| Reason Code | รหัสสาเหตุของ NG เช่น MISSING, EXTRA, FOREIGN ช่วยหน้างานแก้ปัญหา |

### AI
| คำศัพท์ | ความหมาย |
|---|---|
| Traditional CV vs AI ★ | Traditional CV = **คนเขียนกฎ**เอง (สี ขนาด ขอบ)  AI = **เรียนรู้กฎจากตัวอย่าง**ภาพที่มีเฉลย |
| Classification ★ | จำแนกว่า**ทั้งภาพ**เป็นประเภทอะไร (เช่น OK / NG) **ไม่บอกตำแหน่ง** |
| Object Detection ★ | หาวัตถุในภาพ **บอกทั้งประเภทและตำแหน่ง** (ตีกรอบ) |
| Segmentation | ระบายขอบเขตวัตถุทีละพิกเซล ละเอียดกว่า Detection |
| Dataset | ชุดภาพตัวอย่างสำหรับสอน AI |
| Label | เฉลยที่คนติดให้แต่ละภาพหรือแต่ละกรอบ |
| Training / Test Set | ภาพที่ใช้สอน / ภาพที่แยกไว้วัดผล โมเดลไม่เคยเห็น |
| Features | ตัวเลขที่สรุปลักษณะเด่นของภาพ ให้โมเดลเรียนรู้ |
| Accuracy | % ที่โมเดลทายถูก |
| Confusion Matrix | ตารางเทียบเฉลยกับที่ทาย ดูว่าผิดเป็นประเภทไหน |
| Transfer Learning | นำโมเดลที่สอนมาแล้วมาสอนต่อกับภาพของเรา ใช้ภาพน้อยลง |
