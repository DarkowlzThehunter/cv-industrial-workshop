# ใช้ AI ช่วยเขียนโค้ดต่อจากชุด Workshop นี้

เขียนโค้ดไม่คล่องก็ต่อยอดได้ ถ้ารู้วิธีถาม  ใช้ได้กับ ChatGPT, Claude, Gemini หรือ GitHub Copilot ใน VS Code

## กฎ 3 ข้อของคำถามที่ได้คำตอบดี

1. **บอกไฟล์และตำแหน่ง** เช่น “notebook 06 ข้อ 1 ฟังก์ชัน compare_to_reference”  หรือคัดลอกโค้ดส่วนนั้นไปวาง
2. **บอกสิ่งที่เห็น และสิ่งที่ต้องการ** เช่น “ได้ NG ทุกรูป แต่ชิ้นงานดีควรเป็น OK”  ถ้ามี error ให้คัดลอกข้อความ error ทั้งหมดไปด้วย
3. **ขอให้อธิบายทีละบรรทัด** จะได้เข้าใจและแก้ต่อเองได้ ไม่ใช่แค่คัดลอก

## ตัวอย่างคำถาม

**ปรับใช้กับรูปของตัวเอง**
> ฉันใช้ notebook 10 วิธี reference กับรูปถาดของโรงงาน ถาดดีก็ยังได้ NG เพราะเจอจุดต่างเล็กๆ หลายจุด ควรปรับ diff_threshold และ min_area อย่างไร อธิบายว่าแต่ละค่าทำอะไร

**แก้ error**
> รัน notebook 07 แล้วได้ error นี้ [วาง error ทั้งหมด] ใช้ Mac, Python 3.10 ต้องแก้อย่างไร

**เพิ่มความสามารถ**
> ใน notebook 08 วิธี ROI map ช่วยเพิ่มโซนตรวจว่าสติกเกอร์สีเหลืองต้องอยู่ที่มุมขวาบน (x 700-780, y 20-60) ถ้าไม่มีให้เป็น NG เขียนโค้ดต่อจากฟังก์ชัน check_zone เดิม

**ต่อกล้องจริง**
> ฉันมีโค้ดตรวจใน notebook 10 ที่ใช้รูปจากไฟล์ อยากเปลี่ยนเป็นถ่ายจากกล้อง Basler ทุกครั้งที่กดปุ่ม ใช้ฟังก์ชัน grab_one จาก scripts/vision_camera.py ช่วยเขียนให้

**เปลี่ยนเป็นหน้าจอใช้งาน**
> ช่วยเพิ่มวิธีตรวจแบบเทียบภาพอ้างอิง (จาก notebook 10) เข้าไปใน app/inspection_app.py ให้เลือกได้ในแถบซ้าย

## ใช้ใน VS Code โดยตรง

1. ติดตั้งส่วนเสริม **GitHub Copilot** หรือ **Claude** ใน VS Code
2. เปิดโฟลเดอร์ชุด Workshop ทั้งโฟลเดอร์ (AI จะเห็นไฟล์อื่นประกอบ)
3. เลือกโค้ดส่วนที่ต้องการแก้ แล้วพิมพ์คำถามในช่องแชต

## ข้อควรระวัง

- **ตรวจผลเองเสมอ** AI เขียนโค้ดที่รันได้แต่ตัดสินผิดได้  ทดสอบกับรูปที่รู้คำตอบอยู่แล้วก่อนใช้จริง
- **ความลับของบริษัท** รูปชิ้นงานและแบบสินค้าอาจเป็นความลับ  ตรวจนโยบายบริษัทก่อนอัปโหลดรูปขึ้นบริการ AI ภายนอก  ถามด้วยโค้ดและคำอธิบายแทนรูปได้
- **เริ่มเล็ก** แก้ทีละอย่าง รันทดสอบทุกครั้ง ดีกว่าขอให้ AI เขียนทั้งระบบในครั้งเดียว
